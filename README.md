# Case Management Workbench

Clickable prototype for the HiLabs case management case study.

Open `index.html` for the screen index, or start at `Main.dc.html` (the care manager dashboard) and follow the left rail, the tabs and the Call button.

Each screen is a single self-contained HTML file. Fonts, scripts and data are packed inside it, so the pages work from any static host and offline. All member data is synthetic.

Each screen is designed at 1440 x 900 and scales to fit the browser window, centred, with no scrolling.
